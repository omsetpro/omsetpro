# OmsetPro Contracts

Smart contracts for the OmsetPro physical-collateral financing marketplace on Arc Mainnet.

The contract system will coordinate agreements between borrowers and merchants, USDC funding, collateral handover attestations, repayment, default, and dispute resolution.

## Status

The contracts are currently being migrated from the initial prototype architecture to the OmsetPro Arc Mainnet protocol.

Do not treat the current contracts as production-ready until the Arc Mainnet and USDC migration is complete.
