# OmsetPro

OmsetPro is an onchain marketplace for USDC loans backed by physical collateral.

The protocol connects:

- Borrowers who own physical assets and need liquidity.
- Merchants who provide USDC financing and hold the physical collateral.
- Arbiters who can resolve disputed agreements.

OmsetPro itself does not provide lending capital and does not custody physical assets.

## Network

OmsetPro is being built for Arc Mainnet using USDC.

## Architecture

The application is designed as a lightweight onchain application:

- Next.js
- TypeScript
- Privy
- Wagmi
- Viem
- TanStack Query
- Solidity
- Foundry
- OpenZeppelin
- Arc Mainnet
- USDC

No dedicated VPS, backend database, or indexer is required for the initial version.

## Status

OmsetPro is currently under active development.
